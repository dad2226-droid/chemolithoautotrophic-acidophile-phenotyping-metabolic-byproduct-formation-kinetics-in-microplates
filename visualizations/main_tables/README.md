# Main-text experimental overview tables

Each Markdown file contains the manuscript overview and its caption. Select an experiment ID to open the component records for that group. Each record identifies the acquisition or condition, the source field, and its values or links.

Links are relative to the table file. For text sources, the link label gives the physical line numbers, counting the header as line 1. A viewer that opens only the file can use the displayed lines or the component ID to locate the record. For Table 4, join the condition and acquisition registries on `physical_plate_id`. For Tables 5 and 6, use `condition_ID` to locate the vessel measurements.
