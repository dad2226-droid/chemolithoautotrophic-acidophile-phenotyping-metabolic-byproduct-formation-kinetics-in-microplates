# Table 4. Demonstration tests in acidophile microplate cultures.

The six experiment groups comprise independently inoculated microplates (n<sub>microplate</sub>=438 in total). A₃₈₀ indicates apparent formation of the metabolic byproduct Fe³⁺ in cultures supplied with Fe²⁺. Measured R and scatter-corrected R<sup>*</sup> indicate acidification associated with metabolic H+ release in soluble-S cultures, as defined in Data processing. Additive concentrations use the deposited compound basis, except explicitly specified elemental-Ga concentrations in citric-acid/Ga₂(SO₄)₃ combinations.
