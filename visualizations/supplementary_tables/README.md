# Supplementary tables

Each table caption defines every column in the order it appears. Select a table title to read the caption and the pipe-delimited results in one Markdown file. The figure column identifies the associated panels, including nearby panels when the statistic is reported in the surrounding text. Table rows retain the precision of the analysis exports.

A blank numeric cell indicates that a quantity was unavailable or inapplicable. Counts identify the contributing physical plates, vessels, or independent batches. CI columns are 95% confidence limits unless the table identifies an observed range. The columns `p_value` and `p_holm` give the unadjusted and Holm-adjusted p-values, respectively. Percentages and percentage-point changes are distinguished by the units or metric. In cultures, A380 and the thymol blue pH ratio are indicators of the metabolic byproducts Fe³⁺ and H⁺, respectively. R denotes the measured pH indicator ratio and R* denotes its scatter-corrected counterpart. An asterisk on an absorbance readout denotes subtraction of A750.
